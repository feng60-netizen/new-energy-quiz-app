# 新能源汽车智能测评系统
> 基于Python开发，面向新能源汽车技术专业，手机Pydroid3即可运行，无需电脑。

## 项目简介
本项目是一款面向新能源汽车专业学生的AI辅助学习测评工具，集成专业题库、分类刷题、错题本、故障案例查询功能。
可以按照动力电池、电机电控、高压安全、热管理等板块专项练习，自动记录答题成绩，收集错题反复巩固，同时内置整车故障诊断案例，辅助专业课程学习。

## 功能介绍
1. 随机整套刷题：随机抽取题库进行自测
2. 按专业模块分类刷题：动力电池 / 电机电控 / 高压安全 / 热管理
3. 错题本：自动保存答错题目，支持重复练习
4. 成绩记录：自动保存每次测试答题统计
5. 新能源汽车故障案例查阅：常见整车故障现象、原因、维修方案

## 运行环境
- 运行软件：Pydroid3（安卓手机）
- 编程语言：Python3
- 依赖库：python内置库，**无需额外安装第三方库**

## 使用方法
1. 将 `car_ai.py` 和 `bank.txt` 放到同一个文件夹
2. 在Pydroid3打开car_ai.py，直接运行
3. 根据菜单选择功能，输入选项数字使用
